Unit 01: Introduction to Cyber Security
1.1 Introduction & Fundamentals of Cyber
Cyber Security ka matlab hai computers, servers, mobile devices, networks, aur electronic data ko
unauthorized access (bina permission ghusna), chori, ya damage se bachana. Jaise hum apne ghar
ya dukan mein tala (lock) lagate hain, waise hi digital duniya mein data ko safe rakhne ke liye cyber
security lagayi jaati hai.
Fundamentals of Cyber: Cyber duniya teen cheezon par chalti hai — People (users jo system
chalate hain), Processes (rules aur policies), aur Technology (software aur hardware tools jaise
antivirus aur firewall). Teenon milkar ek surakshit system banate hain.
1.2 Cyber Space and Cyber Crime
Cyber Space: Yeh ek virtual (kalpanik) digital environment hai jahan internet ke zariye saare
computers, networks, websites, aur users aapas mein jude rehte hain (jaise WhatsApp, online
banking, cloud storage).
Cyber Crime: Jab koi vyakti computer ya internet ka galat istemal karke kisi ko nuksan
pahunchata hai ya chori karta hai, use cyber crime kehte hain.
Example Fake bank call karke OTP maangna (Phishing), kisi ka Instagram account hack karna, ya
fake website banakar paise thagna cyber crime hai.

1.4 Cyber Laws and Ethics
Cyber Laws (IT Act 2000 & Amendment 2008): Bharat mein cyber crimes ko rokne ke liye
Information Technology (IT) Act, 2000 banaya gaya hai. Section 43 (data damage), Section 66
(hacking), Section 66C (identity theft), aur Section 66D (cheating by personation) iske mukhya
sections hain.
Cyber Ethics: Internet use karne ke sahi moral rules — kisi ka data bina permission na lena,
copyright ka samman karna, fake news na failana, aur cyberbullying na karna.

2.2 Firewalls and Intrusion Detection/Prevention Systems (IDS/IPS)
Firewall ek security guard ki tarah hai jo network aur internet ke beech khada rehta hai aur rules ke
hisab se traffic ko allow ya block karta hai (jaise Packet Filtering, Stateful Inspection, aur Next-Gen
Firewall).
IDS (Intrusion Detection System): Yeh CCTV camera ki tarah hai — network traffic ko monitor
karta hai aur agar koi attack dikhe to admin ko Alert bhejta hai, par khud block nahi karta.
IPS (Intrusion Prevention System): Yeh active security guard hai — attack ko detect karne ke
saath-saath use turant Block bhi kar deta hai.
2.3 Virtual Private Networks (VPNs)
VPN ek encrypted surakshit tunnel (surang) banata hai aapke device aur server ke beech. Isse
aapka IP address chhup jaata hai aur public Wi-Fi par bhi koi aapka data padh nahi sakta. Mukhya
VPN protocols hain IPSec aur SSL/TLS VPN.
Example Railway station ke free Wi-Fi par banking karne se pehle VPN on karne se data
encrypted ho jaata hai.

2.4 Wireless Network Security
Wi-Fi signals hawa mein travel karte hain, isliye koi bhi aas-paas baithkar unhe pakad sakta hai.
Isse bachne ke liye wireless encryption standards use hote hain:
WEP: Sabse purana aur kamzor (aajkal use nahi hota, minutes mein crack ho jaata hai).
WPA / WPA2: Strong security (WPA2 mein AES encryption hota hai).
WPA3: Sabse naya aur sabse safe standard (brute-force attacks se bachata hai).
Common Wi-Fi Threats: Rogue Access Point (nakli Wi-Fi router) aur Evil Twin Attack (asli
naam jaisa nakli hotspot banakar password churana).

Unit 03: System Security
3.1 Introduction & Operating System (OS) Security
System Security ka matlab hai har individual computer, laptop, ya server ko andar se surakshit
banana. Operating System (Windows, Linux, macOS, Android) hardware aur software ko control
karta hai, isliye iski security sabse zaroori hai.
User Accounts & Least Privilege: Har user ko sirf utni hi permission dena jitni uske kaam ke liye
zaroori hai (rozana kaam ke liye Admin account use nahi karna chahiye).
File System Security: Important folders par Read/Write/Execute permissions set karna aur
BitLocker/FileVault se disk encrypt karna.
3.2 Endpoint Protection
Network se jude har device (laptop, phone, POS machine) ko Endpoint kehte hain. Inhe bachane
ke liye Endpoint Protection Platform (EPP) aur EDR (Endpoint Detection and Response) use hota
hai, jisme Antivirus, Anti-malware, Host-based Firewall, aur USB device control shamil hote hain.
3.3 Patch Management and System Hardening
Patch Management: Software companies jab kisi bug ya security hole (vulnerability) ko theek
karne ke liye update bhejti hain, use Patch kehte hain. Time par update na karne se Zero-Day
Attack ka khatra rehta hai.
System Hardening: System ki kamzoriyan kam karna — jaise bekaar apps uninstall karna,
unused network ports band karna, default passwords badalna, aur auto-run disable karna.

3.4 Virtualization and Cloud Security Basics
Virtualization mein ek hi physical server par software (Hypervisor) ki madad se kai virtual
computers (VMs) chalaye jaate hain. Har VM doosre se alag (isolated) rehta hai, par agar hacker ek
VM se nikal kar Hypervisor par kabza kar le, to use VM Escape kehte hain.
Cloud Security (Shared Responsibility Model): Cloud mein (AWS, Azure, Google Cloud) security
dono ki zimmedari hoti hai — Cloud Provider hardware aur building ki suraksha karta hai, aur
Customer (User) apne data, passwords, aur settings ki suraksha karta hai.

4.3 Hash Functions and Digital Signatures
Hash Function: Yeh kisi bhi file ya password ko ek fixed-length unique fingerprint (hash value)
mein badal deta hai (jaise MD5, SHA-256). Yeh one-way hota hai (hash se wapas asli data nahi
ban sakta) aur Integrity check karta hai.
Digital Signature: Sender apni Private Key se message ke hash ko sign karta hai, aur receiver
sender ki Public Key se verify karta hai. Isse Authentication, Integrity, aur Non-Repudiation
teeno milte hain.
4.4 Public Key Infrastructure (PKI) & SSL/TLS
PKI (Public Key Infrastructure): Yeh ek system hai jo digital certificates banata, manage karta,
aur verify karta hai. Isme CA (Certificate Authority) trusted third party hoti hai jo website ko
X.509 Digital Certificate deti hai (jaise Aadhaar/Passport verification).
SSL/TLS & HTTPS: Jab aap browser mein HTTPS aur padlock icon dekhte hain, to wahan TLS
(Transport Layer Security) kaam kar raha hota hai. Pehle Asymmetric encryption se ek secret
Session Key exchange hoti hai (TLS Handshake), aur phir Symmetric encryption se fast aur safe
communication chalta hai.

Unit 05: Access Control and Authentication
5.1 Introduction & Authentication Methods
System mein kisi ko entry dene ke 4 steps hote hain: Identification (aap kaun hain — Username),
Authentication (saboot dikhaiye — Password/OTP), Authorization (aap kya-kya kar sakte hain —
Permissions), aur Accounting (aapne kya kiya — Logs).
Authentication Methods & Protocols: Passwords/PINs, Smart Cards/Tokens, Biometrics
(Fingerprint/Face ID). Network protocols mein Kerberos (ticket-based authentication), RADIUS
(Wi-Fi/VPN login ke liye), aur OAuth / SAML (web apps ke liye) use hote hain.
5.2 Multi-Factor Authentication (MFA)
Sirf password kaafi nahi hota kyunki wo chori ya hack ho sakta hai. MFA mein login ke liye kam se
kam 2 alag categories ka saboot maanga jaata hai:
1. Something You Know

6.4 Security Testing (SAST, DAST & Pen Testing)
SAST (Static Application Security Testing): Bina software chalaye uske Source Code ko check
karna (White-box testing).
DAST (Dynamic Application Security Testing): Chalti hui website/app par bahar se attack
karke bugs dhundhna (Black-box testing).
Penetration Testing (Pen-Testing): Ethical hackers (White-hat) asli hacker ki tarah system ko
hack karne ki koshish karte hain taaki kamzoriyan pata chalen. Vulnerability Scanning
automated tools se known bugs ki list nikalta hai.

Unit 07: Cyber Threats, Attacks, and Incident Response
7.1 Malware and Advanced Threats
Malware (Malicious Software) aise programs hain jo computer ya mobile ko nuksan pahunchane
ke liye banaye jaate hain:
Virus: Kisi normal file se chipak kar aata hai aur user ke file kholne par failta hai.

Worm: Bina kisi ki madad ke khud-ba-khud network mein ek computer se doosre mein failta hai.
Trojan Horse: Asli/useful app (jaise free game) jaisa dikhta hai par andar se hacker ko backdoor
access deta hai.
Ransomware: Aapki saari files ko lock (encrypt) kar deta hai aur kholne ke liye paise (ransom)
maangta hai.
Spyware & Adware: Spyware chupke se aapki activity/passwords churaata hai; Adware
zabardasti ads dikhata hai.
APT (Advanced Persistent Threat): Skilled hackers ka lamba aur chhupa hua attack jo mahino
tak kisi badi company ya sarkar ke network mein baithkar data chori karta hai.
7.2 Social Engineering Attacks
Computer hack karne ki jagah insaan ke dimag (human psychology) ko dhokha dekar password
ya OTP nikalna Social Engineering kehlata hai:
Phishing: Fake email ya website link bhejkar login/bank details churana (Spear Phishing mein
kisi ek khaas vyakti ko target kiya jaata hai).
Vishing & Smishing: Vishing = Voice call par bank manager bankar OTP maangna; Smishing =
Fake SMS bhejna (e.g., "Electricity bill pending").
Baiting & Tailgating: Baiting = Lalach dekar virus wali USB pen drive lagwana; Tailgating = Kisi
employee ke peeche-peeche bina ID card ke secure office mein ghusna.

7.4 Digital Forensics Basics
Digital Forensics ka matlab hai cyber crime ke baad computer, mobile, ya server se digital saboot
(evidence) scientific tarike se nikalna taaki court mein pesh kiya ja sake. Iske 4 main steps hain:

Unit 08: Emerging Trends and Future of Cyber Security
8.1 Cyber Security in Cloud, IoT, and AI
Cloud Security: Aajkal companies apna data Cloud par rakhti hain. Sabse bada khatra hai
Misconfiguration (galat privacy setting se data public ho jaana) aur insecure APIs.
IoT (Internet of Things) Security: Smart TV, CCTV cameras, smart watches aur Alexa jaise
devices mein aksar weak default passwords hote hain aur updates nahi aate, jinhe hackers
hijacks karke Botnets (DDoS attack army) bana lete hain.
AI in Cyber Security: AI ke dono pehlu hain — Positive: AI seconds mein lakhon logs check
karke unknown attacks pakad leta hai. Negative: Hackers AI se realistic Deepfakes (nakli
video/voice call) aur smart phishing emails bana rahe hain.
8.2 Data Privacy and Protection
Data Privacy ka matlab hai aapki personal information (PII — Personally Identifiable Information
jaise Aadhaar, phone number, photo, bank detail) par aapka control hona. Iske liye duniya mein
GDPR (Europe) aur Bharat mein DPDP Act 2023 (Digital Personal Data Protection Act) banaya
gaya hai. Companies ko user ki Consent (marzi) leni zaroori hai aur sirf utna hi data collect karna
chahiye jitna kaam ke liye chahiye (Data Minimization).

8.4 Career Paths and Professional Ethics
Cyber security mein aaj bahut high-demand careers hain: SOC Analyst (24x7 alerts monitor
karna), Penetration Tester / Ethical Hacker (system test karna), Security Architect (safe network
design karna), Digital Forensics Analyst, aur CISO (Chief Information Security Officer).
Professional Ethics: Ek ethical hacker (White-Hat) hamesha likhit permission (authorization) ke
saath hi testing karta hai, client ka data secret rakhta hai, aur koi bug milne par company ko
chupchap batata hai (Responsible Disclosure) — na ki Black-Hat hackers ki tarah blackmail karta
hai.
