### क्या-क्या कवर हुआ है

- **Unit 1** — AI की परिभाषा, 3 घटक (ML/NLP/Computer Vision), Narrow vs General AI,
  industries पर असर, 5 agent architectures, uninformed/informed search (BFS, DFS,
  Greedy, A* के सूत्र सहित), CSP
- **Unit 2** — Knowledge Representation, Propositional Logic + connectives,
  First-Order Logic और दोनों quantifiers, Inference (Modus Ponens, Forward/Backward
  Chaining, Resolution Refutation), Probabilistic Reasoning और Bayesian Network
- **Unit 3** — Part A NLP: Tokenization, TF-IDF, Word Embeddings, POS tagging,
  Sentiment Analysis, Transformers (BERT/GPT). Part B Computer Vision: Image
  Processing, Object Detection (YOLO/R-CNN), Face Recognition, Segmentation
- **Unit 4** — Kinematics vs Dynamics, Forward/Inverse Kinematics, SLAM, Path
  Planning (A*, Dijkstra, RRT)
- **Unit 5** — Rule-Based Expert System (Knowledge Base + Inference Engine,
  फ़ायदे/सीमाएँ), Fuzzy Logic, Ontologies और Semantic Networks
- **Unit 6** — Minimax (Game Tree, Maximizer/Minimizer, 3 steps), Alpha-Beta
  Pruning, Monte Carlo Tree Search के चारों चरण
- **Unit 7** — Bias के 3 प्रकार और 3 स्रोत, Privacy, AI Governance, Employment पर असर
- **Unit 8** — Explainable AI के 4 फ़ायदे, Edge AI + IoT, Quantum AI, AGI,
  AI Project Lifecycle के 4 चरण
- **Appendix-I** — ChatGPT का उपयोग (students/teachers/professionals), Google Gemini
  के 3 फ़ायदे, AI tools की तुलना

### नोट

- स्रोत PDF Hinglish (रोमन) में थी। साफ़ उच्चारण के लिए ऑडियो **देवनागरी हिंदी** में
  बनाया गया है; तकनीकी शब्द वही रखे गए हैं (जैसे मशीन लर्निंग, टोकनाइज़ेशन, मिनिमैक्स),
  ताकि exam में लिखने में दिक्कत न हो।
- कोई subtopic छोड़ा नहीं गया है — पूरा कंटेंट कवर है, summary नहीं।
- PDF के section 2.1 में छपा logical formula टाइपो की वजह से बिगड़ा हुआ था
  (`∼&sim` जैसा टूटा text)। ऑडियो में मानक साफ़ रूप बोला गया है:
  `p → q ≡ ∼p ∨ q`.
- source PDF की Unit 3 दो-column layout में थी; दोनों कॉलम अलग-अलग निकालकर
  सही क्रम में पढ़े गए हैं।
