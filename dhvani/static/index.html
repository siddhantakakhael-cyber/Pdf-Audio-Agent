    Hinglish ka matlab?

    Yahan Hinglish ka matlab hai Hindi uchcharan aur Roman-Hindi preview. Yeh tool Hindi ko English mein translate nahi karta. Mixed Hindi-English text ke liye online Swara/Madhur zyada suitable ho sakte hain; local voice ka English accent alag ho sakta hai.

    Free, par kuch limits hain

    Local Priyamvada voice bina API key chalti hai. Online voices Microsoft Edge ki unofficial service use karti hain: internet chahiye, aur availability/rate limits guarantee nahi. Is preview ke network mein online service block ho sakti hai; local fallback isi liye hai.

    PDF: 25 MB / 500 pages. Text: 10 lakh characters. Isse badi kitab ko parts mein baantein. Audio length par alag 10-minute cap nahi hai.

    License aur privacy

    Bundled Priyamvada voice ko conservative taur par non-commercial/personal use maana gaya hai; commercial use se pehle upstream dataset license verify karein. Code GPL-3.0-or-later hai. Local mode mein text third-party TTS ko nahi bheja jata. Online mode mein sirf text chunks Microsoft ko jate hain, PDF nahi. Yeh public production service nahi hai; sensitive documents ke liye apne private computer par chalayein.

    Audio fail ho to?

    Online voice fail ho to “Local voice par retry” dabayein. Local model missing ho to setup script chalayein. Password-locked PDF pehle unlock karein. Scanned PDF mein OCR on rakhein aur scan saaf ho to behtar result milega.
